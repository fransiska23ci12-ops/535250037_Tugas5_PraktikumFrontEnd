## Deskripsi Project

Kopi Senja merupakan website coffee shop
yang dibuat menggunakan Next.js, TypeScript,
React Bootstrap, dan Bootstrap.

Website ini merupakan single page website
yang menampilkan informasi mengenai kedai kopi,
daftar menu, keunggulan, dan informasi kontak.

## Fitur Website

1. Responsive Navigation Bar
2. Hero Section menggunakan React Bootstrap Carousel
3. Three Sliding Banners
4. About Us Section
5. Our Coffee Menu
6. Why Choose Us Section
7. Contact Section
8. Footer
9. Responsive Design

## Teknologi yang Digunakan

- Next.js
- TypeScript
- React Bootstrap
- Bootstrap 5
- CSS

## Struktur Website

- Home
- About
- Menu
- Why Us

- Footer

## Cara Menjalankan Project

1. Clone repository:

   git clone URL_REPOSITORY

2. Masuk ke folder project:

   cd kopi-senja

3. Install dependencies:

   npm install

4. Jalankan website:

   npm run dev

5. Buka browser:

   http://localhost:3000
